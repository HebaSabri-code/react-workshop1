# React Workshop 1

A React project for practising components and props by recreating the LITE.SHOP product listing page from the workshop reference.

## Technologies

- React
- Vite
- TypeScript
- Tailwind CSS
- lucide-react

## Run locally

Use Node.js 22.12+ or 24+ and npm.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Progress

- Set up the React and TypeScript project with Vite.
- Configure Tailwind CSS and install lucide-react.
- Replace the starter page with a simple LITE.SHOP page.

## Components and props

`App` is the main component. It currently displays the project title and a short description.

No custom props are needed in this setup step. The shop sections and reusable components will be added in the next steps, and this README will be updated with their props.
